# UmaShow 界面规范

参考：[LearnHub educational platform](https://www.uupm.cc/demo/educational-platform)。采用奶油白底、深色描边、绿色操作和少量天蓝、珊瑚色。不要使用浅薰衣草底或紫色品牌色。

## 颜色与层级

| 用途 | 色值 |
| --- | --- |
| 页面底色 | `#fffaf5` |
| 卡片、弹窗标题、导航、工具栏 | `#f5efdf` |
| 正文 / 描边 | `#303744` / `#343b49` |
| 次要文字 | `#626975` |
| 明亮主按钮 / 按钮文字 | `#4bc65a` / `#173520` |
| 链接、选中状态 | `#24783d` |
| 选中底色 | `#e6f7df` |
| 次要按钮 | `#b6dce9` |
| 少量装饰强调 | `#fac0b4` |

Tailwind 的旧 `indigo` 类映射为绿色品牌色，避免逐页遗留紫色操作。游戏内属性、稀有度、技能分类等已有语义色不随品牌色更换。

面板禁止使用纯白底。旧 `bg-white` 及其透明度变体通过 Tailwind 的 `backgroundColor.white` 桥接到 `--uma-clay-surface-rgb`，覆盖记录页、账号配置及编辑工具栏；`text-white` 等前景颜色保持不变。新增面板使用 `var(--uma-clay-surface)`，输入框使用较浅的奶油底，靠边线表达可编辑性。

页面内容优先使用开放分区、标题、留白和细分隔线。独立的详设、预设条目保留一层浅奶油色卡片、16px 圆角和轻阴影；列表外围不再套卡片，卡片内部也不再套装饰框。育成、继承马娘的选择入口保留可点击卡片，未选使用奶油底，已选统一浅绿底、绿色边线和左侧标记。选择弹窗内容区与登录配置使用相同奶油底色和公共按钮。输入框保留浅底以明确可编辑性。表格与历史记录使用紧凑行，禁用浮起和缩放装饰。

立体外框集中在弹窗和主操作：2px 深色边线，按钮 10px、弹窗 20px 圆角；2×3px 控件阴影或 5×6px 弹窗阴影。菜单栏和辅助导航使用暖奶油底、浅暖灰分隔与轻阴影，不使用黑色硬底边。不要给每层容器叠加阴影。手机全屏弹窗无圆角和外阴影。

运行控制区和当前育成进度各使用一张独立任务卡片；历史列表按日期或任务组拆成独立卡片，卡片之间 16px 间距，组内仍用紧凑数据行。历史视图切换工具栏放在卡片列表外，避免整页套一层大卡片。

## 字体

中文、英文、普通数字统一使用本地 Noto Sans SC variable，字重 100–900，常用 400、500、600、700。正文 16px、表单和数据 14px、标签 13px、注释 12px、分节标题 18px、页标题 24px。表格与数值使用 tabular-nums，不再另换等宽字体；代码文本保留系统等宽字体。

字体来源：Google Fonts 的 [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，采用 SIL Open Font License 1.1。授权文件随 Web 和桌面构建复制至 `licenses/NotoSansSC-OFL.txt`。

初始 UI 使用约 0.76 MB 子集；罕见姓名、导入内容按需回退至完整约 7.8 MB 字体，同一字体设计，运行不依赖 Google Fonts 网络。更新界面或数据库后运行 `python python/subset_ui_font.py`（依赖 fonttools、brotli）。完整字体始终覆盖子集以外字符。

## 动画

按下 120ms、颜色反馈 160ms、弹窗进入 220ms、关闭 120ms。采用 `cubic-bezier(0.23, 1, 0.32, 1)`，仅过渡指定属性。弹窗从 0.98 倍、8px 位移进入；不变换整页或遮罩，避免固定定位的子弹窗被困在父层。

键盘操作立即响应；遵循系统减少动态效果偏好。触屏不保留悬停缩放，后台暂停循环动画。进度条用 scaleX；高频数值直接更新，反馈保持短暂；不添加常驻跳动、页面切换等待或无意义装饰动画。
